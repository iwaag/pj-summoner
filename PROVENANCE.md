# Provenance

summoner is developed as a managed project in a private Gitea repository of its owner's agdev
installation, which is its development authority. This public repository is an **edited derivative
with its own history**: its first commit is a single root commit with no earlier history, and later
commits are made by an explicit publication step. A public commit's message names the internal
commit it was made from.

Left out on purpose: the run records of the proposals made while developing it, the project's
workflow for publishing it, and the publication contract itself. Everything else is the project as it
stands: `project.yaml`, the agent's guides and the workflow definitions. The README is written for
this repository; it is not the internal one.
